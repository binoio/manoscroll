ManoScroll

Hands-free scrolling for macOS using AI hand gesture recognition.

Download Latest Release

Features

  • Hand Gesture Scrolling: Use open palm and closed fist gestures to scroll.
  • Background Operation: Works while other apps are in focus.
  • Configurable: Fine-tune sensitivity and detection thresholds.
  • Native macOS: Built with Swift and Vision framework.

Quick Start

Launch ManoScroll, click "Start Tracking", and position your hand in front of the camera.
